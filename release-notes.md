# CampusMate 0.3.3

Added smooth page-entry transitions to the Mac and phone apps. Web transitions respect the device's reduced-motion setting and only run when switching pages. The first-launch overview and dark theme remain included.

## Install on Mac

1. Download and unzip `CampusMate-macOS-arm64.zip`.
2. Move `CampusMate.app` to Applications.
3. Open CampusMate. If macOS blocks it because the app is not Developer ID signed or notarized, Control-click it and choose **Open**.

This build is for Apple silicon. The Mac AI Tutor requires Ollama and the `llama3.2:3b` model; all other features work without it.
