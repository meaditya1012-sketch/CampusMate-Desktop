# CampusMate 0.1.0

CampusMate is now available as a downloadable macOS desktop app for Apple silicon.

## What's included

- Student dashboard with today's classes, pending tasks, and attendance summary
- Weekly schedule, tasks, attendance tracking, study notes, and Pomodoro timer
- Optional AI Tutor powered by a local Ollama installation
- Local per-user database storage

## Install

1. Download and unzip `CampusMate-macOS-arm64.zip`.
2. Move `CampusMate.app` to Applications.
3. Open CampusMate. If macOS blocks the app because it is not Developer ID signed, Control-click it and choose **Open**.

The AI Tutor requires Ollama and the `llama3.2:3b` model. All other features work without it.
